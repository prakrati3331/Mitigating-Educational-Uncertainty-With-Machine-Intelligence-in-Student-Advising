# Mitigating-Educational-Uncertainty-With-Machine-Intelligence-in-Student-Advising


An AI-powered student advising platform designed to help learners make informed academic and career decisions. This system blends machine intelligence, predictive analytics, and a hybrid AI–human mentorship model to support students—especially those in rural and semi-urban areas with limited access to professional counseling.

# Overview

Students across India often struggle with choosing the right stream, course, or career due to lack of awareness, scattered information, and limited guidance. This project addresses these gaps by providing a real-time, personalized, multilingual, and offline-capable advising solution built using modern AI/ML methodologies.

Our platform supports: Smart career recommendations Early detection of dropout risks Scholarship & admission notifications Career pathway visualization Real-time job market insights Offline-first architecture for low bandwidth users

# Key Features

🔹 AI-Driven Career Guidance

Recommends suitable courses and career paths based on aptitude, interests, and behavioral indicators.

🔹 Dropout Risk Prediction

Uses academic, socio-economic, institutional, and personal attributes to flag at-risk students early.

🔹 Real-Time Academic & Scholarship Alerts

Notifies students about admissions, deadlines, scholarships, and financial aid opportunities.

🔹 Multilingual & Culturally Adaptive Interface

Designed to be accessible in rural and semi-urban regions with diverse linguistic needs.

🔹 Offline-First Functionality

Works smoothly on low-bandwidth (even 2G) networks with online sync capability.

🔹 Hybrid AI + Human Mentorship

Ensures accuracy and reliability with counselor oversight.

🔹 E-Book Directory & Resources

Provides curated PDFs, guidance material, and state-level educational information.

🔹 AI Tutor Agent & Quiz Generator Agent

🔹 Mistral Agent

# Innovation & Uniqueness

Predictive analytics for early student intervention

Offline-first, low-bandwidth UI for rural learners

Career visualization and skill mapping

Integrates job market trends for future career readiness

Inclusive design supporting digital literacy gaps

# Technology Stack

Frontend: HTML5, CSS3, JavaScript React.js, TailwindCSS Streamlit for ML interface modules

Backend: FastAPI Flask Node.js AI/ML Scikit-learn TensorFlow/Keras NLTK Mistral AI + LangChain NumPy, Pandas

Database: MongoDB JSON Pickle (ML models)

Visualization: Matplotlib D3.js

Security: JWT Authentication Encrypted user data

# Testing & Validation

User Validation: Tested with real-world scenarios to ensure accuracy and usability

Performance Testing: Ensured smooth operation even in low-bandwidth environments
